Also noted — verified, but not deepening candidates

  • Three modes are parseable but unreachable. SharedPermutation, JacobianDump and ReductionShadow each have exactly one reference — the parser at research_options.h:130/132/134. Nothing acts on them, yet enabled() is switchOn && mode != Off, so it returns true for a mode no code implements. A user setting one gets research-predicates firing with no collector behind them.
  • Floating point in the live-QE ranking. live_qe_prefix scores candidates with std::exp / std::log (worker_snapshot.cpp:2063–2064), unlike the integer hash sampler. Cross-platform bit-identity of the intervention therefore depends on libm — worth a decision on a branch that treats determinism as load-bearing.
  • Test-only back doors in both loggers. test_arm_for_unit_tests / test_disarm_for_unit_tests sit in the public interface of both Recorder and InternalDatasetLog.
  • A doc/code mismatch in the inherited quantile. weighted_quantile's docstring claimed normalisation "by the total weight"; the code divides by the last midpoint. Behaviour preserved (correcting it would move the isotonic bin edges and change published numbers); the documentation was corrected in place.
  • One genuinely deep seam already exists. The TTAccess template on Worker::search with ResearchTTOverlay as its adapter is the model to copy: a 92-line interface hiding copy-on-first-access clusters, with the search generic over it and zero research branches in the TT access path.
Top recommendation

One numeric module for ridge, IRLS logistic, PAV and AUC

Tackle this first. It is the only candidate that is a correctness hazard rather than a navigation cost: the report and the learnability/ranking probes compute AUC, ridge and IRLS logistic from independent implementations with different tie handling and convergence rules, and the branch's entire output is numeric claims. A silent disagreement between them invalidates evidence without failing anything. It is also the cheapest to fix and the easiest to verify — a shared module with the two call sites diffed against each other — and unlike the structural candidates it needs no change to the search path, so it cannot trip the unchanged-behaviour invariant.

For the larger structural payoffs, take the rows module (it unlocks all six analysis scripts) and the decision-node object (it is the biggest interface in the branch and the one the engine's hot loop has to reason about).
